# Vertex Learning Platform

Vertex is an AI-powered learning platform featuring intelligent content search, modular course authoring, and timestamped video discovery.

## Features

- **Vertex Design System**: Complete design system with curated typography (Inter + Playfair Display), custom palette, accessible components, and interactive showcase.
- **UI Component Library**: Buttons, Badges, Cards, Dropdowns, Inputs, Status Indicators, and Navigation built with Tailwind CSS v4.
- **Intelligent Video & Lesson Discovery**: Plain-language AI search grounding results directly to timestamped moments in video lessons.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the design system showcase and application.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (`Inter` & `Playfair Display`)
